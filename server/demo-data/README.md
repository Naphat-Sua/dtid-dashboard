## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `cases_import.csv` | นำเข้าคดีผ่านหน้า Admin › Import Cases from CSV (`POST /api/upload/csv`) |
| `related_data.sql` | บุคคล ที่อยู่ ของกลาง บุคคล-คดี ความสัมพันธ์ (ระบบไม่มีตัวนำเข้า CSV สำหรับตารางเหล่านี้ จึงโหลดด้วย psql แบบเดียวกับ `db:seed`) โยงกับคดีด้วยเลขคดี และโยงบุคคลด้วยเลขบัตร |

| `analysis_results.json` | ผลวิเคราะห์ทั้งหมดพร้อมพารามิเตอร์ (สร้างโดย `scripts/runDemoAnalysis.mjs`) |
| `figures/` | รูปประกอบ: `kde_map.png`, `gistar_hotspots.png`, `corridors.png` และภาพหน้าจอแอป `app_*.png` |

## ขั้นตอนนำเข้า

```bash
cd server
npm run db:create && npm run db:schema && npm run db:seed:users   # ฐานข้อมูลใหม่ ไม่ต้องรัน db:seed (ชุดเก่า)
npm run dev
# เข้าระบบ admin / admin1234 → Import Cases from CSV → เลือก demo-data/cases_import.csv
psql -U postgres -d dtid_dashboard -f demo-data/related_data.sql
```

ผลการนำเข้า: **Successfully imported 216 of 216 records** (Errors 0, ไม่มีแถวถูกข้าม, ไม่ต้อง geocode เพราะมีพิกัดครบ)
`related_data.sql` รันซ้ำได้โดยไม่เกิดข้อมูลซ้ำ
